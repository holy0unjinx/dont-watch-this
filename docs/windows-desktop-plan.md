# windows 섹션 로드맵

Win7 향수 데스크톱을 실제로 동작하는 데스크톱으로 만든다. 항목마다 브랜치를
따고, 검증 후 main에 병합한다.

## 구조 변경 (1번에서 함께)

가로 스크롤 갤러리(`.windows-track`, 휠 하이재킹)를 단일 데스크톱으로 바꾼다.
최소화/최대화/포커스/작업표시줄/스냅이 모두 "화면 하나" 위에서만 성립하기
때문이다. 창은 절대 배치되고 서로 겹칠 수 있다 — 데스크톱에서는 그게 정상.

## 항목

- [x] 1. 창 동작: 최소화/최대화/닫기, 타이틀바 드래그 이동, 클릭 시 앞으로
      (z-order), 활성/비활성 유리 상태
- [x] 2. 작업표시줄: 유리 바, 시작 오브 + 시작 메뉴(프로그램 실행), 열린 창
      버튼, 실제 시각 시계, 닫은 창 재실행용 데스크톱 아이콘
- [x] 3. 제어판 → DOOM: 제어판을 열면 표시 설정 대신 DOOM이 실행된다
      (vendor/wasm-doom, MIT, 셰어웨어 WAD 내장). 원래 계획했던 테마 설정은
      사용자 요청으로 폐기
- [x] 4. 지뢰찾기 창: 8x8/지뢰 10, 첫 클릭 안전, 깃발, 타이머 — 보드 로직은
      순수 함수로 분리해 테스트
- [ ] 5. 탐색기를 진짜 파일 목록으로: model.obj 선택 시에만 3D 미리보기,
      content/results 마크다운을 문서로 나열하고 메모장 창에서 열기
- [x] 6. 그림판 작동: 팔레트 색 선택, 캔버스 낙서, 지우기
- [ ] 7. 부팅 연출: 섹션 진입 시 부팅 스플래시 → 로그온 → 데스크톱 (1회)
- [ ] 8. Aero 디테일: 좌우 절반 스냅, 작업표시줄 호버 미리보기(Peek),
      비활성 창 블러

## 규칙

- 순수 로직(보드 규칙, 창 사각형 계산 등)은 DOM과 분리해 node:test로 검증
- 브라우저 렌더는 이 환경에서 확인 불가(chromium 실행 불가) — 사용자 확인 필요
